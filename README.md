Este protótipo tem como objetivo devolver a autonomia de pessoas com dificuldade de leitura, baixa visão e/ou deficientes visuais durante suas compras. Basta apontar a câmera do seu celular para o código de barras que o aplicativo lê em voz alta as informações do produto.

### O QUE O APP PRETENDE FAZER:

- Lê marca, tipo de produto, ingredientes e informações nutricionais do produto escaneado
- Contém configurações como tamanho de fonte, idioma e voz utilizados
- Permite que o usuário digite manualmente o código de barras caso prefira
- Permite que o usuário pesquise por marcas parceiras, tendo certeza de que a que procura está no sistema

### LIMITAÇÕES ATUAIS:

- Atualmente, o projeto é apenas um protótipo, onde parte das funções são simuladas para fins de demonstração
- Mudança funcional de idiomas não implementada
- TTS (Text-to-Speech) integrado não implementado
